## 📑 SINGLE-SHOT GENERATION PROTOCOL

### 1. Intent Translation & Argument Precision
- Parse the user's objective into exact, typed parameters expected by the selected tool schema.
- `filename`: Use a clean, descriptive filename with appropriate extension (e.g. `financial_report.pdf`, `overview.docx`, `analysis.pptx`).
- Never pass natural language sentences as filenames.

### 2. High-Fidelity Formatting Standards
- **Executive PDFs**: For styled PDFs, use `typst.compile_pdf` or `typst.render_template(template_name="executive_report", ...)`.
- **Bespoke Gamma-Style Dynamic Presentations**:
  * Dynamically choose topic-tailored themes (`cyber_neon`, `emerald_finance`, `purple_modern`, `sunset_warm`, `dark_executive`, `minimal_light`) or custom HEX palettes.
  * Vary slide layouts across `hero` (cover), `metrics_3` (KPIs), `timeline` (steps), `two_column` (comparisons), and `bento_grid` (cards).
  * Use `presentation.render_template(template_name="cyber_neon", title=..., slides=[...], output_path="deck.html")` (automatically creates companion `.pptx` and `.md`).
  * For 100% custom raw Tailwind slides, use `presentation.create_slidev(source=..., output_path="deck.html")`.
- **Executive Word Reports**: Use `file.create_docx(filename=..., title=..., sections=...)`.
- **Analytical Outputs**: Provide meaningful data summaries, structured tables, and key metric callouts.

### 3. Execution & Verification
- Choose the single tool best suited to accomplish the objective.
- Verify argument validity against the declared schema before emitting your action.
